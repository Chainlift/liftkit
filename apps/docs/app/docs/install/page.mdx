# Install

LiftKit is in alpha, so it's published under the `next` tag. Run this command in your project:

```bash
npm i liftkit@next
```

LiftKit needs React 19. It works with Next.js and any other bundler that handles CSS imports.

## Import the styles

Import the stylesheet once, in your app's root. It contains the design tokens, the utility classes, and the styles for every component.

```tsx
import "liftkit/styles.css";
```

## Use a component

Import any component from `liftkit`:

```tsx
import { Button } from "liftkit";

export default function Page() {
  return <Button label="Hello" variant="fill" color="primary" />;
}
```

## Import a single component

Each component is also available on its own path:

```tsx
import { Select } from "liftkit/select";
```

Either way, your bundler only includes the components you use.
